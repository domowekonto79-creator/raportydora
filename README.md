# Raportydora

Potrzebuje zrobić stronę pod dedykowana reklamę  jednej z moich usług kompletnie - dora as a service. Nie mam niestety żadnych grafik, tam jest głównie raportowanie excelli do knf oraz czynności  wynikające z procedor i polityk klienta. Chxe sie rowniez skupic na raportowaniu sprpf27, 27, 18, 01 itd. Strona ma opisywać ta usługę a ruch ma być skierowany z Google ads i może jeszcze innych reklam - jeszcze nie wiem dokładnie jak to zrobić. Co zaproponujesz do stworzenia kontentu oraz strony?
